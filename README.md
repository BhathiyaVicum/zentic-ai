## 📖 About The Project

**ZenticAI** is a production-grade RAG (Retrieval-Augmented Generation) platform that transforms static study materials into an interactive, AI-powered knowledge base.

Unlike standard note-taking apps, ZenticAI allows users to upload complex documents (PDFs, research papers, lecture notes) and engage in contextual dialogue with their own data.

### ✨ Core Features

| Feature | Description |
|---------|-------------|
| 🔍 **Vector Search** | Finds semantic meaning, not just keywords. Understands context like a human. |
| 📄 **Page Citations** | Every answer includes exact page numbers. Verify sources instantly. |
| 💬 **Cross-Document Chat** | Upload multiple PDFs and ask questions across all of them simultaneously. |
| ⚡ **Instant Summaries** | Get quick insights without reading entire documents. |
